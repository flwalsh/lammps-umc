The "main" branch contains the currently developed version of unconstrained MC in LAMMPS as standalone "fix umc." It has been tested with the 30Mar2026 release. Simply copy the MC folder into src/.

Documentation is in progress.

This "paper" branch contains the older version that was actually used in "Finite-temperature grain boundary phases, transformations, and diagrams in alloys." Example scripts are also included.

This code was built on top of the 29Aug2024 release and requires the replacement of several files. It should not be used except as needed to reproduce results from that study.

LLNL code is approved for release as an incremental contribution to LAMMPS.
